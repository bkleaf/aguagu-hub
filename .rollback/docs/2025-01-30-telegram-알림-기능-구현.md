# Telegram 알림 기능 구현

**작성일**: 2025-01-30

---

## 1. 구현 내용

카드 결제 문자 처리 후 Telegram Bot을 통해 실시간 알림을 전송하는 기능을 구현함.

---

## 2. 추가된 파일

### 2.1 TelegramProperties.kt

**경로**: `src/main/kotlin/com/woo/server/common/config/TelegramProperties.kt`

```kotlin
@ConfigurationProperties(prefix = "telegram")
data class TelegramProperties(
    val botToken: String = "",
    val chatId: String = "",
    val enabled: Boolean = false
)
```

- `@ConfigurationPropertiesScan`을 `AguaguHubApplication`에 적용하여 자동 스캔
- 환경변수로 오버라이드 가능: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_ENABLED`

### 2.2 TelegramNotificationService.kt

**경로**: `src/main/kotlin/com/woo/server/common/notification/TelegramNotificationService.kt`

**주요 기능**:
- `notifyTransaction(transaction: CardTransaction)` — 거래 저장 후 알림 전송
- `buildSuccessMessage(tx)` — 파싱 성공 시 결제 정보 포맷팅
- `buildFailMessage(tx)` — 파싱 실패 시 실패 사유 및 원문 포맷팅
- `sendMessage(text)` — Telegram Bot API (`sendMessage`) 호출 (RestClient 사용)

**알림 형식**:
- 성공: 카드사, 금액, 사용처, 일시, 누적액
- 실패: 카드사, 실패 사유, 원본 메시지

### 2.3 telegram-test.http

**경로**: `src/test/http/telegram-test.http`

- 성공 케이스 테스트 (삼성카드 정상 문자)
- 실패 케이스 테스트 (파싱 불가 문자)
- Telegram Bot API 직접 호출 테스트

---

## 3. 변경된 파일

| 파일 | 변경 내용 |
|------|----------|
| `AguaguHubApplication.kt` | `@ConfigurationPropertiesScan` 추가 |
| `CardTransactionService.kt` | `TelegramNotificationService` 의존성 추가, 거래 저장 후 알림 호출 |
| `application.properties` | `telegram.bot-token`, `telegram.chat-id`, `telegram.enabled` 설정 추가 |

---

## 4. 연동 흐름

```
카드 문자 수신 (POST /api/v1/card/transactions)
    ↓
CardTransactionService.processCardMessage()
    ↓
파싱 → 중복 확인 → DB 저장
    ↓
TelegramNotificationService.notifyTransaction()
    ↓
Telegram Bot API (sendMessage) → 사용자 Telegram 채팅방
```

---

## 5. 설정 방법

`application.properties` 또는 환경변수로 설정:

```properties
telegram.bot-token=${TELEGRAM_BOT_TOKEN:봇토큰}
telegram.chat-id=${TELEGRAM_CHAT_ID:챗ID}
telegram.enabled=${TELEGRAM_ENABLED:true}
```

`enabled=false`로 설정하면 알림을 비활성화할 수 있음.
