# 2026-02-03 하나카드/KB카드 파서 수정

---

## 1. 하나카드 정규식 수정

### 문제

한 줄 승인 정규식에서 `\s+누적` 부분이 공백을 필수로 요구했으나, 일부 문자에서 사용처와 "누적" 사이에 공백이 없음.

### 해결

`\s+누적` → `\s*누적` (공백 유무 모두 처리)

## 2. KB카드 중간형 형식 추가

### 문자 형식

```
KB국민카드4043승인
전*우님
13,200원 일시불
02/03 19:49
(주)케이티
누적369,985원
```

### 변경 내용 (KbCardParser.kt)

- `FORMAT3_AMOUNT_PATTERN`, `FORMAT3_DATETIME_PATTERN`, `FORMAT3_ACCUMULATED_PATTERN` 정규식 추가
- 형식 구분: `승인시간` 키워드 → 형식1, 금액+날짜 같은 줄 → 형식2, 금액+일시불/날짜 별도 줄 → 형식3

### KB카드 파서 지원 형식

| 형식 | 식별 조건 |
|------|-----------|
| 형식 1 (상세형) | `승인시간` 키워드 포함 |
| 형식 2 (간략형) | `금액원 MM/DD` 패턴 (같은 줄) |
| 형식 3 (중간형) | `금액원 일시불` + `MM/DD HH:MM` (별도 줄) |

## 3. 마스킹 카드번호 매칭 설명

하나카드 파서는 `7*2*` 그대로 추출. 원본 `7929`와의 매칭은 `CreditCardService.findByCardInfo()`에서 처리:

```
SMS "하나7*2*" → 파서 추출 "7*2*" → LIKE 패턴 "7_2_" → DB "7929" 매칭 → 거래 "7929"로 저장
```

전제 조건: 신용카드 관리에서 `HANA_7929`로 등록되어 있어야 함.
