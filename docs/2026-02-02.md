# 2026-02-02 하나카드 한 줄 승인 형식 파싱 추가

---

## 배경

기존 하나카드 파서는 여러 줄 승인/취소 2가지 형식만 지원. 한 줄 승인 형식을 추가.

## 신규 지원 형식

```
MG+ 하나7*2*승인 전*우 11,200원 일시불 02/02 15:30 호랑마켓광장점 누적1,160,487원
```

## 변경 내용 (HanaCardParser.kt)

- `COMPACT_APPROVAL_PATTERN` 정규식 추가
- `canParse()`: 한 줄 승인 형식 인식 조건 추가
- `parse()`: 여러 줄 승인 / 한 줄 승인 / 취소 3가지 분기
- `parseCompactApproval()` 메서드 신규 추가

## 하나카드 파서 지원 형식

| 형식 | 식별 조건 |
|------|-----------|
| 여러 줄 승인 | `"금액"` + `"사용처"` 키워드 포함 |
| 한 줄 승인 | `COMPACT_APPROVAL_PATTERN` 정규식 매칭 |
| 취소 | `"취소"` 키워드 포함 |
