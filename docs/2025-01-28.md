# 2025-01-28 HTTP Client 설정 및 API 테스트 수정

---

## 1. `{{host}}` 변수 설정

`http-client.env.json` 파일을 프로젝트 루트에 생성하여 환경별 변수를 정의.

```json
{
  "dev": { "host": "http://localhost:8080" },
  "prod": { "host": "https://your-production-server.com" }
}
```

## 2. 이슈 해결

### URL 중복 문제

`.http` 파일에서 `http://{{host}}/...` 형태로 작성되어 프로토콜이 중복됨.

```http
# 수정 전
POST http://{{host}}/api/v1/card/transactions

# 수정 후
POST {{host}}/api/v1/card/transactions
```

### 환경 파일 위치

IntelliJ HTTP Client는 **프로젝트 루트**에서 `http-client.env.json`을 찾는 것이 기본 동작.
- `src/test/http/http-client.env.json` 삭제 → 프로젝트 루트로 이동

### 카드사별 필터링 API 경로

`GET /api/v1/card/transactions?cardCompany=SAMSUNG` → 쿼리 파라미터 무시됨 (전체 조회 실행).

```http
# 수정 전 (동작하지 않음)
GET {{host}}/api/v1/card/transactions?cardCompany=SAMSUNG

# 수정 후 (정상 동작)
GET {{host}}/api/v1/card/transactions/by-company/SAMSUNG
```
