## 1. Telegram 알림 기능 구현

카드 결제 문자 처리 후 Telegram Bot을 통해 실시간 알림을 전송하는 기능을 구현함.

### 추가된 파일

| 파일 | 설명 |
|------|------|
| `common/config/TelegramProperties.kt` | Telegram 설정 속성 (`@ConfigurationProperties`) |
| `common/notification/TelegramNotificationService.kt` | 거래 알림 전송 서비스 |
| `src/test/http/telegram-test.http` | Telegram 테스트 파일 |

### 연동 흐름

```
카드 문자 수신 (POST /api/v1/card/transactions)
  → CardTransactionService.processCardMessage()
  → 파싱 → 중복 확인 → DB 저장
  → TelegramNotificationService.notifyTransaction()
  → Telegram Bot API (sendMessage) → 사용자 채팅방
```

### 설정 방법

```properties
telegram.bot-token=${TELEGRAM_BOT_TOKEN:봇토큰}
telegram.chat-id=${TELEGRAM_CHAT_ID:챗ID}
telegram.enabled=${TELEGRAM_ENABLED:true}
```

## 2. 카드 한도(CardLimit) 기능 구현

카드별 월간 한도를 설정하고, 거래 알림 시 한도 대비 사용 현황을 함께 제공하는 기능을 구현함.

### 추가된 파일

| 파일 | 설명 |
|------|------|
| `entity/CardLimit.kt` | 카드 한도 JPA 엔티티 |
| `repository/CardLimitRepository.kt` | Spring Data JPA 리포지토리 |
| `service/CardLimitService.kt` | 한도 CRUD 및 사용액 집계 |
| `controller/CardLimitController.kt` | REST API 컨트롤러 |
| `dto/CardLimitDto.kt` | 요청/응답 DTO |
| `src/test/http/card-limits.http` | HTTP 테스트 파일 |

### API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| POST | `/api/v1/card/limits` | 카드 한도 생성/수정 (upsert) |
| GET | `/api/v1/card/limits` | 전체 한도 조회 |
| GET | `/api/v1/card/limits/{id}` | 단건 한도 조회 |
| DELETE | `/api/v1/card/limits/{id}` | 한도 삭제 |

## 3. 이슈 수정, Swagger 추가, 테스트 코드 구현

### 3.1 HTTP 테스트 파일 이슈 수정

- `card-transactions.http`: `receivedAt` → `phoneNumber` 변경 반영
- `card-limits.http`: 하드코딩 URL → `{{host}}` 변수 사용으로 변경

### 3.2 Swagger (springdoc-openapi) 추가

Spring Boot 4.0.1은 springdoc-openapi 2.x와 호환되지 않아 **3.0.0-M1**(milestone) 사용.

```kotlin
// build.gradle.kts
repositories {
    mavenCentral()
    maven { url = uri("https://repo.spring.io/milestone") }
}
dependencies {
    implementation("org.springdoc:springdoc-openapi-starter-webmvc-ui:3.0.0-M1")
}
```

- `OpenApiConfig.kt` 추가 (API 제목, 설명, 버전)
- `CardTransactionController`, `CardLimitController`에 `@Tag`, `@Operation` 어노테이션 추가
- 접속: `http://localhost:8080/swagger-ui/index.html`

### 3.3 테스트 코드 구현

**CardTransactionControllerTest.kt** (9개 테스트, `@WebMvcTest`):
- 삼성카드 결제 문자 등록 성공/파싱 실패/필수 필드 누락
- 전체/특정/카드사별/파싱 실패/성공 거래 조회
- 지원 카드사 목록 조회

**CardLimitControllerTest.kt** (6개 테스트, `@WebMvcTest`):
- 카드 한도 설정/필수 필드 누락
- 전체/단건 한도 조회 (존재/미존재)
- 한도 삭제 (성공/미존재)

**CardTransactionIntegrationTest.kt** (`@SpringBootTest`):
- 실제 DB + Telegram 연동 전체 흐름 시나리오 테스트

> **Spring Boot 4.0 주의**: `@WebMvcTest`, `@AutoConfigureMockMvc`의 패키지가 `o.s.boot.webmvc.test.autoconfigure`로 변경됨.

## 4. 어드민 프론트엔드 구현

Vite + Vue 3 + Vuetify 3 기반 어드민 프론트엔드를 `front/` 디렉토리에 구현.

### 프로젝트 구조

```
front/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.js
    ├── App.vue
    ├── router/index.js
    ├── api/index.js
    ├── layouts/DefaultLayout.vue
    └── views/
        ├── DashboardView.vue
        ├── TransactionListView.vue
        ├── TransactionCreateView.vue
        └── LimitListView.vue
```

### 페이지 구성

| 경로 | 페이지 | 기능 |
|------|--------|------|
| `/` | 대시보드 | 거래 건수 요약 + 최근 거래 5건 |
| `/transactions` | 거래 내역 | 전체/성공/실패 탭, 카드사 필터, 상세 다이얼로그 |
| `/transactions/new` | 문자 등록 | 전화번호 + 문자 메시지 입력, POST 호출 |
| `/limits` | 카드 한도 관리 | 한도 목록, 추가/수정/삭제 다이얼로그 |

### Spring Boot 연동

- `vite.config.js`: `build.outDir`을 `../src/main/resources/static`으로 설정
- `WebConfig.kt`: SPA 폴백 설정 (Vue Router history 모드 지원)
- 빌드: `cd front && npm run build` → `./gradlew bootRun`으로 통합 서빙
