# 2026-02-18 자동결제 관리 기능 구현

---

## 개요

카드별로 매월 반복되는 정기 결제(넷플릭스, 보험료, 통신비 등)를 등록하고 관리하는 기능. 등록된 CreditCard에 연결하여 카드별 자동결제 내역을 확인할 수 있다.

## DDL (수동 실행 필요)

```sql
CREATE TABLE aguagu.auto_payments (
    id BIGSERIAL PRIMARY KEY,
    credit_card_id VARCHAR(30) NOT NULL REFERENCES aguagu.credit_cards(id),
    description VARCHAR(100) NOT NULL,
    amount NUMERIC(15, 2) NOT NULL,
    payment_day INTEGER NOT NULL,
    active BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMP NOT NULL DEFAULT now(),
    updated_at TIMESTAMP NOT NULL DEFAULT now()
);
```

## 백엔드 신규 파일

| 파일 | 설명 |
|------|------|
| `entity/AutoPayment.kt` | 자동결제 엔티티 (CreditCard `@ManyToOne` 참조) |
| `repository/AutoPaymentRepository.kt` | 카드별 조회, 활성 금액 합산 쿼리 |
| `dto/AutoPaymentDto.kt` | Request/Response DTO |
| `service/AutoPaymentService.kt` | CRUD + 활성 금액 합산 |
| `controller/AutoPaymentController.kt` | REST API |

## API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| POST | `/api/v1/card/auto-payments` | 자동결제 등록 |
| GET | `/api/v1/card/auto-payments` | 전체 조회 |
| GET | `/api/v1/card/auto-payments/{id}` | 단건 조회 |
| GET | `/api/v1/card/auto-payments/by-card/{creditCardId}` | 카드별 조회 |
| PUT | `/api/v1/card/auto-payments/{id}` | 수정 |
| DELETE | `/api/v1/card/auto-payments/{id}` | 삭제 |
