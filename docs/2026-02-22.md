# 2026-02-22 태그 Main/Detail 분리 구현

## 개요

거래(CardTransaction)에 할당되는 태그를 **주요(MAIN) 태그**와 **세부(DETAIL) 태그**로 분리하여, 거래의 주요 분류와 세부 분류를 구분할 수 있도록 구현하였습니다.

### 핵심 규칙
- **MAIN 태그**: 거래당 최대 1개 (필수 아님, 사용자가 후에 할당)
- **DETAIL 태그**: 거래당 0개 이상
- 같은 태그가 거래별로 MAIN/DETAIL 자유롭게 사용 가능

---

## 변경 내역

### 1. DDL (수동 실행 필요)

**파일**: `docs/sql/tag-type-migration.sql`

- `transaction_tags` 테이블에 `tag_type VARCHAR(10) NOT NULL DEFAULT 'DETAIL'` 컬럼 추가
- 기존 데이터 마이그레이션: 각 거래의 첫 번째 태그를 MAIN으로 변경
- Partial unique index: 거래당 MAIN 태그 최대 1개 제약
