# 2025-01-29 phone_number 컬럼 마이그레이션 이슈

---

## 문제 상황

`card_transactions` 테이블에 `phone_number` 컬럼을 `NOT NULL`로 추가하려 했으나, 기존 데이터에 값이 없어 DDL 실행 실패.

```
ERROR: column "phone_number" of relation "card_transactions" contains null values
```

## 해결

```sql
UPDATE card_transactions SET phone_number = 'unknown' WHERE phone_number IS NULL;
ALTER TABLE card_transactions ALTER COLUMN phone_number SET NOT NULL;
```

## 후속 변경

### phoneNumber 필드 nullable 변경

- `@Column(nullable = false, length = 20)` → `@Column(length = 20)` (nullable = true)
- 타입: `String` → `String?`

### Hibernate ddl-auto 변경

- `ddl-auto=update` → `ddl-auto=validate`로 변경
- 스키마 변경을 Hibernate가 자동 수행하지 않고 검증만 수행
- DB 스키마: `aguagu` (`spring.jpa.properties.hibernate.default_schema=aguagu`)

### CardMessageRequest DTO 변경

- `receivedAt` 필드 제거, `phoneNumber` 필드 추가
