# 2026-02-20 카드별 사용 현황 대시보드 및 모바일 메뉴 변경

## 요구사항

1. PC 대시보드의 "이번 달 최근 거래 내역" 테이블을 **카드별 사용 현황** 섹션으로 교체
2. 자동결제 금액은 합산하지 않음
3. 잔여금액은 월별이 아닌 **한도 유형의 기간(MONTHLY/YEARLY/CUSTOM)** 기준으로 계산
4. 모바일 대시보드에도 동일하게 적용
5. 모바일 하단 네비게이션에서 "카드" 메뉴를 "청구서"로 교체, "카드 관리"는 "더보기" 하위로 이동

---

## 변경 사항

### 1. 백엔드 — DTO 신규 생성

**파일**: `src/main/kotlin/com/woo/server/domain/card/dto/CardUsageSummaryDto.kt` (신규)

- `CardUsageSummaryResponse` — 개별 카드 사용 현황 응답
  - `creditCardId`, `cardCompany`, `cardCompanyName`, `lastFourDigits`
  - `billingStartDay`, `billingEndDay`, `periodStart`, `periodEnd` (정산기간)
  - `usedAmount` (정산기간 거래 합산)
  - `hasLimit`, `limitType`, `limitTypeName`, `limitAmount`
  - `limitUsedAmount` (한도 기간 내 사용액)
  - `remaining` (한도 기간 기준 잔여), `usagePercent` (한도 기간 기준 사용률)
- `UsageSummaryOverview` — 전체 요약
  - `cards: List<CardUsageSummaryResponse>`, `totalUsedAmount`

### 2. 백엔드 — CardLimitService 메서드 접근제어 변경

**파일**: `src/main/kotlin/com/woo/server/domain/card/service/CardLimitService.kt` (수정)

- `calculateBillingPeriod()`: `private` → `internal` (CardUsageSummaryService에서 호출)
- `buildCardDigitVariants()`: `private` → `internal` (CardUsageSummaryService에서 호출)

### 3. 백엔드 — CardUsageSummaryService 신규 생성

**파일**: `src/main/kotlin/com/woo/server/domain/card/service/CardUsageSummaryService.kt` (신규)

- 의존성: `CreditCardRepository`, `CardLimitRepository`, `CardTransactionRepository`, `CardLimitService`
- `getUsageSummary(): UsageSummaryOverview` 메서드:
  1. 활성 카드 조회 (`findByActiveTrue()`)
  2. 각 카드별: 정산기간 사용액, 한도 조회, **한도 유형별 기간으로 사용액 별도 계산**
  3. 전체 합산 반환
- `calculateLimitPeriod()` private 메서드:
  - MONTHLY → 정산기간 (billingStartDay ~ billingEndDay)
  - YEARLY → 현재 년 1/1 ~ 12/31
  - CUSTOM → customStartDate ~ customEndDate

### 4. 백엔드 — CreditCardController 엔드포인트 추가

**파일**: `src/main/kotlin/com/woo/server/domain/card/controller/CreditCardController.kt` (수정)

- `CardUsageSummaryService` 생성자 주입 추가
- `GET /api/v1/card/credit-cards/usage-summary` 엔드포인트 추가
- Swagger `@Operation(summary = "카드별 사용 현황 요약 조회")` 어노테이션

### 5. HTTP 테스트 추가

## 논의 및 수정 과정

1. **초기 계획**: 자동결제 금액 포함하여 합산하는 것으로 설계
2. **사용자 요청 #1**: "자동결제는 합산하지 말아줘" → DTO/서비스/프론트에서 자동결제 관련 필드 및 로직 전부 제거
3. **사용자 요청 #2**: "잔여금액 계산은 월별이 아닌 한도 기간내 잔여금액으로" → 한도 유형(MONTHLY/YEARLY/CUSTOM)별 기간으로 사용액을 별도 계산하여 `limitUsedAmount` 필드 추가, 잔여/사용률은 한도 기간 기준으로 변경
4. **사용자 요청 #3**: "모바일 화면도 동일하게 적용" → 모바일 대시보드에 카드별 사용 현황 적용
5. **사용자 요청 #4**: "모바일 하단 메뉴에서 카드 대신 월별 청구서" → 하단 네비게이션 메뉴 교체
6. **사용자 요청 #5**: "카드 관리가 더보기에서 안 보임" → MoreView.vue에서 "월별 청구서" 항목을 "카드 관리"로 교체
