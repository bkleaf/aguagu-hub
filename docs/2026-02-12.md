# 2026-02-12 QNAP NAS Docker 배포 설정

---

## 배포 방식

**로컬 빌드 → tar 전송 → Docker Compose 실행**

```
[개발 PC (Windows)]              [QNAP NAS]
 ① Docker 멀티스테이지 빌드       ④ docker load
 ② docker save → .tar            ⑤ docker compose up -d
 ③ SCP로 NAS 전송 ──────────→
```

## 추가/변경된 파일

| 파일 | 설명 |
|------|------|
| `Dockerfile` | 멀티스테이지 빌드 (프론트엔드 + 백엔드 + 런타임) |
| `docker-compose.yml` | NAS 배포용 Compose 설정 |
| `.env.example` | 환경변수 템플릿 |
| `.dockerignore` | 불필요 파일 제외 |
| `deploy.bat` | Windows용 자동 배포 스크립트 |

## 배포 절차

### 자동 배포 (deploy.bat)

`deploy.bat`의 `NAS_USER`, `NAS_HOST`, `NAS_DEPLOY_DIR` 설정 후 실행.

### 수동 배포

```bash
docker build -t aguagu-hub:latest .
docker save -o aguagu-hub.tar aguagu-hub:latest
scp aguagu-hub.tar admin@NAS_IP:/share/Container/aguagu-hub/
ssh admin@NAS_IP "cd /share/Container/aguagu-hub && docker load -i aguagu-hub.tar && docker compose up -d"
```

## 환경변수 (.env)

NAS 배포 디렉토리에 `.env` 파일 필요 (`.env.example` 참조):
- `APP_PORT`, `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_ENABLED`, `TELEGRAM_WEBHOOK_URL`
- `JAVA_OPTS` (메모리 설정)

## Dockerfile 구조

```
Stage 1: frontend-build (node:22-alpine) → Vue 앱 빌드
Stage 2: backend-build (eclipse-temurin:25-jdk-alpine) → Gradle bootJar
Stage 3: runtime (eclipse-temurin:25-jre-alpine) → app.jar 실행
```

## 주의사항

- NAS에서 PostgreSQL 호스트 네트워크 접근 확인 필요
- Telegram 웹훅은 외부 접근 시 포트포워딩/리버스 프록시 필요
- `.env` 파일은 git에 커밋하지 않도록 주의
